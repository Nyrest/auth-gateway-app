# Auth Gateway Agent Skills

This directory is the package documentation root referenced by TanStack Intent. The
canonical source for each skill lives beside its `SKILL.md` under `skills/<name>/README.md`.
Keeping the source document beside the skill makes review and stale detection local to
the package while this index gives Intent a stable documentation entry point.

Use the package README for installation and the consumer-side, deny-by-default loading
policy. Editor hooks may offer convenience, but the host process must enforce the policy.
